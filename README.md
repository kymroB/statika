# СТАТИКА 2.0 — персональное PWA-приложение

Рабочая версия курса на 12 недель (36 занятий) с двумя режимами: **Обучение** и **Тренировка**. Работает на Mac, iPhone и Pixel через браузер. Для облачной синхронизации потребуется настроить собственный проект Supabase; без него работает локальный дневник.

## 1. Сначала запуск на Mac — без установки программ

1. **Скачайте архив `statika-pwa-v2.zip`.**
2. Дважды щёлкните по архиву, чтобы macOS распаковала его.
3. Откройте полученную папку `statika-pwa-v2` (или похожее название, заданное системой при распаковке).
4. Найдите **`index.html`**. Нажмите правой кнопкой мыши → **Открыть с помощью → Google Chrome**.
5. Появится главная страница **«Статика 2.0»**.
6. Откройте **Обучение** и попробуйте переключить упражнение / «Правильно» / «Ошибки».
7. Откройте **Программа → Неделя 1 → День 1 → Начать тренировку**.
8. Нажмите **«Начать упражнение»**: прозвучат сигналы **3–2–1**, затем начнётся удержание, после него **автоматический отдых** и следующий подход. **После последнего подхода упражнения переход к следующему — только по кнопке**.
9. Если хотите проверить упражнение без физического выполнения, можете отметить тестовые подходы, но не путайте их с фактическими тренировками.

Важно: при открытии файла напрямую через Chrome будут работать интерфейс и локальный дневник, но это **ещё не установка PWA**. Установка на главный экран телефона требует локального веб-сервера (`localhost`) либо публикации по HTTPS. Эти шаги можно выполнить после местного тестирования.

### Как проверить полноценную веб-версию на Mac (необязательно)

1. Откройте **Терминал** в macOS: `Cmd + Пробел`, напечатайте `Терминал` и откройте приложение.
2. Введите `cd ` (после `cd` должен быть пробел), перетащите папку `statika-pwa-v2` из Finder в окно Терминала, нажмите Enter.
3. Выполните команду: `python3 -m http.server 8000`. Если macOS сообщит, что Python не установлен, остановитесь — не нужно устанавливать неизвестные программы, уточним отдельно.
4. Откройте в Chrome: `http://localhost:8000`.
5. Для завершения работы сервера нажмите в Терминале `Ctrl + C`.

**Не переходите на новое локальное адресное пространство без резервной копии:** браузер хранит данные `file://` и `http://localhost:8000` раздельно. Перенести тренировки можно через **Экспорт / Импорт JSON**.

## 2. Как перенести записи из первой версии

Важнейший шаг: **сначала сохраните резервную копию в версии 1.0**, если ещё не сделали этого.

1. Откройте старую «Статику 1.0».
2. Перейдите **Дневник → Экспорт JSON**. Будет скачан файл вида `statika-diary-2026-11-14.json`.
3. Откройте **Статику 2.0 → Аккаунт → Импорт**.
4. Выберите ранее выгруженный JSON.
5. Перейдите в **Дневник** и убедитесь, что подходы и значения на месте.
6. Повторный импорт того же файла не должен дублировать существующие записи: проверка ведётся по уникальным ID.

Приложение продолжает использовать **формат резервной копии `statika-diary-v1`** для совместимости. **Не удаляйте исходный файл** до завершения тестирования v2 и синхронизации.

## 3. Что изменилось в версии 2.0

- **Обучение:** 17 упражнений, упрощённые авторские схемы правильных положений и распространённых ошибок, текстовая техника и облегчённые варианты. Схемы пока не являются полноценным видео/GIF и не заменяют проверку техники у тренера.
- **Тренировка:** один ручной запуск упражнения, отсчёт 3–2–1 со звуками, удержание, автоматическая запись секунд, автоматический отдых и следующий подход. После последнего подхода **новое упражнение запускается вручную**.
- **Повторения:** вместо секунд введение фактически выполненного числа повторений вручную; затем отдых запускается автоматически.
- **Варианты на две стороны:** отдельные удержания для левой и правой стороны, чередование внутри одной серии.
- **Аудио:** звуки по умолчанию включены, голос необязателен, переключатели доступны на тренировочном экране; длительность отдыха можно выбрать от 30 до 120 секунд.
- **Пауза:** при уходе в другой раздел или скрытии вкладки таймер останавливается, время сохраняется в памяти открытой страницы и может быть продолжено при возврате к тому же занятию.
- **Статусы:** «В процессе», «Выполнено частично», «Выполнено полностью». От простого просмотра программа не создаёт пустые записи в дневнике.
- **Дневник:** записи локально сохраняются, доступна корректировка отдельного подхода и перенос резервной копии из версии 1.0.

### Ограничения таймера

Телефонный браузер может заблокировать или задержать звук, особенно если экран погас. Поэтому **не рассчитывайте на сигналы с выключенным экраном**. Во время тренировки держите приложение открытым на видимом экране; при уходе из вкладки программа ставит отсчёт на паузу. Тестировать громкость и надёжность звуков нужно на конкретном телефоне после публикации.

### Нагрузка и техника

Программа — ориентир, а не обязательный норматив. Переход к следующему этапу допустим только при уверенной технике. Не задерживайте дыхание. Если появляется боль, выраженное головокружение или нестандартное ухудшение самочувствия, прекращайте упражнение. Схематичные изображения полезны как напоминание, но не заменяют очное обучение сложным элементам.

## 4. Где хранятся данные

В локальном режиме данные сохраняются в браузере на **этом конкретном устройстве**. Экспорт и импорт доступны в «Аккаунте». Не удаляйте данные сайта до создания резервной копии. Если Chrome открыл новую папку или иной URL, локальное хранилище может отличаться от прежнего — тогда перенесите записи через JSON.

При настройке Supabase клиент использует `config.js` или параметры из страницы «Аккаунт». **Пока Supabase не настроен, настоящего облачного входа и синхронизации нет.**

## 5. Настроить Supabase позже — после тестирования

1. Создайте **свой** проект на https://supabase.com/.
2. В Supabase откройте **SQL Editor**, вставьте содержимое файла `schema.sql` и выполните запрос. Это создаст таблицу `workout_sessions` с RLS-политиками, по которым каждый пользователь видит только свои записи.
3. В **Authentication → Providers** настройте вход по email и подтверждение адреса.
4. В панели проекта найдите **Project URL** и **Publishable key** (начинается с `sb_publishable_`). Никогда не указывайте секретный `sb_secret_` или `service_role`.
5. В `config.js` заполните:

```js
window.STATICFIT_CONFIG = {
  supabaseUrl: 'https://YOUR_PROJECT.supabase.co',
  supabasePublishableKey: 'sb_publishable_YOUR_PUBLIC_KEY'
};
```

6. Опубликуйте файлы на HTTPS-хостинге, например GitHub Pages (см. ниже).
7. В Supabase **Authentication → URL Configuration** добавьте фактический URL сайта в **Site URL** и **Redirect URLs** для подтверждения email.
8. На опубликованной версии войдите в аккаунт на первом телефоне и импортируйте локальный JSON при необходимости. На втором телефоне войдите под тем же email.

Реальная синхронизация **не проверялась на действующем проекте Supabase** — до её проверки важно сохранять JSON-копии.

## 6. Публикация на GitHub Pages

1. Создайте репозиторий, например `statika`.
2. Загрузите в корень файлы `index.html`, `app.js`, `visuals.js`, `styles.css`, `config.js`, `sw.js`, `manifest.webmanifest`, `schema.sql`, `README.md`, а также папку `icons/`.
3. **Settings → Pages → Deploy from a branch**, выберите `main` и `/ (root)`.
4. После публикации откройте `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/statika/`.
5. На iPhone: **Safari → Поделиться → На экран «Домой»**. На Pixel/GrapheneOS: в браузере выберите **«Установить приложение»** или **«Добавить на главный экран»**.

PWA-кэш обновлён до `statika-app-v2.0.0`. Если ранее публиковали версию 1.0, обновление кэша произойдёт после повторного открытия сайта с интернетом.

## 7. Особенности первой рабочей версии 2.0

- Схемы упражнений статичны, без встроенных видео/GIF. Они авторские и схематичные; демонстрации ещё требуют проверки перед использованием как основного обучающего материала.
- План на 12 недель содержит календарную прогрессию; **автоматической индивидуальной адаптации сложности на основании освоенных навыков пока нет**. Менять уровень на более сложный без устойчивой техники не рекомендуется.
- При одновременном редактировании одной тренировки на двух устройствах возможно столкновение изменений; не редактируйте одну запись параллельно.
- Офлайн-режим и установка PWA работают при корректной публикации на HTTPS, но не при простом `file://`-открытии.

## 8. Содержимое папки

- `index.html` — оболочка приложения.
- `app.js` — тренировочный план, автоматический цикл, дневник, облачная синхронизация.
- `visuals.js` — векторные схемы 17 упражнений.
- `styles.css` — адаптивный интерфейс.
- `config.js` — публичные настройки Supabase.
- `schema.sql` — база данных и политики доступа.
- `manifest.webmanifest`, `sw.js`, `icons/` — PWA-установка и офлайн-кэш.
